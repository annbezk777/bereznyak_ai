**Старый ROI-калькулятор заменён** на **интерактивный квиз** для подбора тарифа!

---

## 🎯 Что это такое:

**Пошаговый опросник** из 7 вопросов, который:
1. Собирает данные о бизнесе клиента
2. Анализирует требования
3. Рассчитывает стоимость разработки
4. Рекомендует тариф (LITE/PRO/ULTRA)

---

## 📝 7 вопросов квиза:

### 1. **Вид деятельности** 📋
- Текстовое поле для ввода
- Примеры: "Грузоперевозки", "Установка окон", "Детейлинг авто"

### 2. **Сколько параметров влияет на цену?** 📊
- 2-3 параметра → простой расчёт
- 4-7 параметров → средняя сложность
- 8+ параметров → сложные формулы

### 3. **Как сейчас считаете цены?** 💻
- Excel / Калькуляторы
- Прайс-листы
- В голове менеджера
- У каждого своя система

### 4. **Нужна ли смета на руки?** 📄
- Да, в PDF с печатью
- В сообщении (текстом)
- Только озвучить цену

### 5. **Сколько заявок в месяц?** 📈
- До 50 заявок
- 50-200 заявок
- Более 200 заявок

### 6. **Куда попадает заявка?** 📨
- Email/Telegram менеджеру
- В CRM-систему (AmoCRM/Bitrix24)
- Своя система / Админ-панель

### 7. **Сколько менеджеров?** 👥
- 1 менеджер
- 2-3 менеджера
- 4+ менеджеров

## 🧮 Логика расчёта стоимости:

### Базовые тарифы:

```javascript
2-3 параметра = LITE (55 000₽)
4-7 параметров = PRO (150 000₽)
8+ параметров = ULTRA (350 000₽)
```

### Множители:

```javascript
+ PDF-генерация → +40 000₽ (переход на PRO)
+ CRM-интеграция → +50 000₽ (переход на PRO)
+ Своя система → +120 000₽ (переход на ULTRA)
+ Высокая нагрузка (200+ заявок) → ×1.2 (20%)
```

### Пример расчёта:

```
Входные данные:
- 5 параметров → PRO (150 000₽)
- Нужен PDF → уже включено в PRO
- Интеграция с AmoCRM → уже включено в PRO
- Заявок 250/мес → ×1.2 = 180 000₽

ИТОГО: 180 000₽, тариф PRO
```

## 🔧 Навигация:

### Кнопки:
- **← Назад** — возврат на предыдущий шаг (появляется со 2-го шага)
- **Далее →** — переход на следующий шаг (активна только при заполнении)

### Автоматическая валидация:
- Шаг 1: текст должен быть введён (min 1 символ)
- Шаги 2-7: должна быть выбрана одна опция
- Кнопка "Далее" неактивна (серая) пока шаг не заполнен
