## 📱 Как протестировать:

1. Откройте `index.html` в браузере
2. Прокрутите до секции "Готовы автоматизировать продажи?"
3. Нажмите **"Запустить демо-бот в мессенджере"**
4. Модалка откроется ✨
5. Кликните на **"Международная логистика"**
6. Откроется Telegram бот @prime_shift_bot

## 🔧 Если нужно изменить:

### Добавить новый бот:
Найдите блок с комментарием:
```html
<!-- BOT 2: Детейлинг-центр (COMING SOON) -->
```

Измените:
1. Класс `opacity-60 cursor-not-allowed` → уберите
2. Добавьте `<a href="https://t.me/ваш_бот" target="_blank">`
3. Бейдж "Скоро" → "✓ Доступен"
4. Цвета границ `border-slate-700` → `border-blue-500/40`

### Изменить ссылку на бота логистики:
Найдите строку:
```html
<a href="https://t.me/prime_shift_bot" target="_blank"
```

Замените ссылку на новую.
