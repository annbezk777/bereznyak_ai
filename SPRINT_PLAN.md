### **ЭТАП 2: Webhook или сервер для отправки**

#### **Вариант А: Через Telegram Bot API (рекомендую)**

**Задача 2.1: Создать простой сервер на Node.js / Python / PHP**

**Что делает сервер:**
1. Принимает POST-запрос с данными формы
2. Форматирует сообщение
3. Отправляет в Telegram через Bot API

**Пример структуры:**
```
POST /send-lead
Body: {
  name: "Иван Иванов",
  contact: "+7 999 123-45-67",
  tier: "PRO",
  price: "120 000 – 180 000₽",
  business: "Грузоперевозки",
  comment: "Хочу обсудить интеграцию с 1С"
}

→ Отправка в Telegram
```

**Опции:**

- **Make (Integromat)** (бесплатно до 1000 операций/мес)
- **n8n** (self-hosted, бесплатно)

**НУЖНО:**
```javascript
// Отправляем на сервер
fetch('https://ВАШ_СЕРВЕР/send-lead', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        name: name,
        contact: contact,
        tier: consultationData.tier,
        price: consultationData.price,
        business: consultationData.business,
        comment: comment
    })
})
.then(response => response.json())
.then(data => {
    alert('✅ Заявка отправлена! Мы свяжемся с вами в течение 2 часов.');
    closeConsultationModal();
})
.catch(error => {
    alert('❌ Ошибка отправки. Попробуйте позже или напишите напрямую: hello@bezk.pro');
});
```
