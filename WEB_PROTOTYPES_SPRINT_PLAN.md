## 📦 ПРОЕКТ 1: Международная логистика

### Спринт 1: Создание веб-прототипа (2-3 дня)

#### День 1: Базовый UI

**Задачи:**
- [ ] Создать HTML структуру чата
- [ ] CSS стили в стиле Telegram
  - Голубая шапка с названием бота
  - Белые пузыри для сообщений бота (слева)
  - Зеленые пузыри для ответов пользователя (справа)
  - Тени, скругления, Telegram-like дизайн
- [ ] Адаптивная верстка (desktop 375px-1920px, mobile)
- [ ] Шрифты: SF Pro Display / Roboto

**Компоненты UI:**
```html
<div class="chat-container">
    <header class="chat-header">
        <div class="bot-avatar">🛫</div>
        <div class="bot-info">
            <div class="bot-name">Логистический Бот</div>
            <div class="bot-status">онлайн</div>
        </div>
    </header>

    <div class="messages-container">
        <!-- Сообщения здесь -->
    </div>

    <div class="input-container">
        <input type="text" placeholder="Введите сообщение...">
        <button>Отправить</button>
    </div>
</div>
```

#### День 2: Интерактивность и диалог

**Задачи:**
- [ ] JavaScript для управления диалогом
- [ ] Анимация печати сообщений бота (typing indicator)
- [ ] Inline кнопки (выбор транспорта, подтверждение и т.д.)
- [ ] Логика перехода между шагами диалога

**Сценарий диалога:**

```javascript
const dialogFlow = {
    step1: {
        botMessage: "👋 Добро пожаловать! Рассчитаю стоимость импорта за 2 минуты.\n\n🚚 Выберите тип транспорта:",
        buttons: [
            {text: "✈️ Авиа", next: "step2_air"},
            {text: "🚢 Море", next: "step2_sea"},
            {text: "🚂 ЖД", next: "step2_rail"},
            {text: "🚛 Авто", next: "step2_road"}
        ]
    },

    step2_air: {
        botMessage: "✈️ Отлично! Расчет авиадоставки.\n\n📦 Введите код ТН ВЭД или название товара:",
        inputType: "text",
        placeholder: "Например: 8471300000 или ноутбуки",
        next: "step3"
    },

    step3: {
        botMessage: "🔍 Нашел по коду 8471300000:\n\n📦 Товар: Портативные ЭВМ (ноутбуки)\n💰 Ставка пошлины: 0%\n📊 Ставка НДС: 20%\n✅ Требуется сертификация: Да\n\n➡️ Это верный товар?",
        buttons: [
            {text: "✅ Да, верно", next: "step4"},
            {text: "❌ Другой товар", next: "step2_air"}
        ]
    },

    step4: {
        botMessage: "⚖️ Введите вес груза в килограммах:",
        inputType: "number",
        placeholder: "Например: 150",
        next: "step5"
    },

    step5: {
        botMessage: "⏳ Рассчитываю стоимость...",
        delay: 2000,
        next: "step6"
    },

    step6: {
        botMessage: `💰 РАСЧЕТ ЗАВЕРШЕН!

📊 ДЕТАЛИ РАСЧЕТА:

Груз:
• Код ТН ВЭД: 8471300000
• Наименование: Портативные ЭВМ
• Вес: 150 кг
• Маршрут: Гуанчжоу → Москва (авиа)

Стоимость доставки:
✈️ Авиаперевозка: $750
📦 Упаковка: $50
🏢 Таможенное оформление: $200

Таможенные платежи:
🧾 Пошлина (0%): $0
💵 НДС (20%): $400
🏷️ КИЗ: не требуется

Сертификация:
📄 ТР ЕАЭС 037/2016: $300

═══════════════════
💎 ИТОГО: $1,700
⏱️ Срок: 7-10 дней
═══════════════════

📩 Хотите получить расчет?`,
        buttons: [
            {text: "📧 Отправить на email", next: "email"},
            {text: "🔄 Новый расчет", next: "step1"}
        ]
    }
};
```

#### День 3: Полировка и анимации

**Задачи:**
- [ ] Анимация появления сообщений (fade-in)
- [ ] Typing indicator (три точки "...")
- [ ] Плавная прокрутка к новым сообщениям
- [ ] Звуковые эффекты (опционально)
- [ ] Сохранение истории в localStorage
- [ ] Кнопка "Начать заново"

**Дополнительные фичи:**
- Эмодзи в сообщениях
- Время отправки сообщений
- Счетчик непрочитанных (если свернуто)
- Favicon с иконкой бота

## 📦 ПРОЕКТ 2: Кондиционеры под ключ

### Спринт 2: Веб-прототип (2-3 дня)

#### День 1: UI + Базовый диалог

**Отличия от логистики:**
- Другая цветовая схема (фиолетовый градиент)
- Карточки пакетов услуг
- Календарь выбора даты (визуальный компонент)

**Диалог:**
```
1. Приветствие + выбор типа объекта
2. Ввод площади помещения
3. Выбор модели кондиционера (карточки)
4. Расчет + выбор пакета (Базовый/Оптимальный/Премиум)
5. Календарь бригад (визуальная сетка)
6. Выбор бокса
7. Подтверждение заказа
```

#### День 2: Календарь бригад

**Компонент календаря:**

## 🛠 ТЕХНИЧЕСКИЙ СТЕК

### Frontend:
- **HTML5** - семантическая разметка
- **CSS3** - Grid, Flexbox, анимации
- **JavaScript (Vanilla)** - без фреймворков для простоты
