## 🔴 BLOCKER - Критические баги (блокируют работу)

### BUG #1: Telegram Bot Token в открытом коде
**Severity:** 🔴 Blocker
**Страница:** index.html (строка 3596)
**Приоритет:** МАКСИМАЛЬНЫЙ

**Описание:**
Токен Telegram бота хранится в открытом виде в JavaScript коде:
```javascript
const botToken = '8171742276:AAHOdnAPPql_8MEsS60bxBAa1PJoCcX7P-w';
const chatId = '1337987399';
```

**Шаги воспроизведения:**
1. Открыть https://bezk.pro/
2. F12 → View Page Source
3. Ctrl+F поиск "botToken"
4. Токен виден в открытом виде

**Фактический результат:**
Любой пользователь может скопировать токен и получить полный доступ к боту

**Ожидаемый результат:**
Токен должен храниться на backend (Node.js/PHP/Python), на фронте только вызов API

**Риски:**
- ❌ Злоумышленник может отправлять спам от имени бота
- ❌ Утечка данных клиентов
- ❌ Telegram может заблокировать бот за abuse
- ❌ DDoS на бот через публичный токен

**Рекомендуемое решение:**
1. Создать backend endpoint (например, `/api/send-lead`)
2. Переместить логику отправки в Telegram на сервер
3. С фронта отправлять только данные формы через fetch на свой API
4. Перевыпустить токен бота через @BotFather

**Статус:** 🚨 ТРЕБУЕТ НЕМЕДЛЕННОГО ИСПРАВЛЕНИЯ

### BUG #2: URL /demo не работает (404)
**Severity:** 🔴 Blocker
**Страница:** /demo
**Приоритет:** Высокий

**Описание:**
Пользователь не может открыть страницу демо-ботов по адресу bezk.pro/demo

**Шаги воспроизведения:**
1. Открыть https://bezk.pro/demo
2. Наблюдать ошибку 404

**Фактический результат:**
Страница не найдена (404 Not Found)

**Ожидаемый результат:**
Должна открываться страница с демо-ботами

**Причина:**
Файл называется `demo.html`, но сервер не настроен на обработку URL без расширения

**Решение:**
**Вариант A (Рекомендуется):** Настроить редирект на сервере:
- Apache: добавить в .htaccess
  ```apache
  RewriteRule ^demo$ demo.html [L]
  ```
- Nginx: добавить в конфиг
  ```nginx
  rewrite ^/demo$ /demo.html last;
  ```

**Вариант B:** Везде использовать полный URL `/demo.html` вместо `/demo`

**Workaround (временное решение):**
Открывать через https://bezk.pro/demo.html (работает корректно)

**Статус:** 🔴 Open

## 🟠 CRITICAL - Высокий приоритет

### BUG #3: Отсутствие мета-тегов на главной странице
**Severity:** 🟠 Critical
**Страница:** index.html
**Влияние:** SEO, социальные сети

**Описание:**
В `<head>` главной страницы отсутствуют критически важные meta-теги

**Что отсутствует:**
```html
<title>Bereznyak AI - ...</title> ✅ ЕСТЬ
<meta name="description" content="..."> ✅ ЕСТЬ
<meta name="viewport" content="..."> ❌ НЕТ
<meta property="og:title" content="..."> ❌ НЕТ
<meta property="og:description" content="..."> ❌ НЕТ
<meta property="og:image" content="..."> ❌ НЕТ
<meta name="twitter:card" content="..."> ❌ НЕТ
```

**Фактический результат:**
- Сайт может некорректно отображаться на мобильных устройствах (нет viewport)
- При шейре в соцсетях не будет превью с картинкой и описанием

**Ожидаемый результат:**
Полный набор мета-тегов для SEO и соцсетей

**Рекомендуемое решение:**
Добавить в `<head>`:
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta property="og:title" content="Bereznyak AI - Боты для B2B">
<meta property="og:description" content="...">
<meta property="og:image" content="https://bezk.pro/og-image.png">
<meta property="og:url" content="https://bezk.pro/">
```

**Статус:** 🟠 Open

### BUG #9: Cookie Banner может показываться несколько раз
**Severity:** 🟡 Major
**Страница:** Все страницы

**Описание:**
При тестировании localStorage - если пользователь очистит данные браузера, баннер появится снова (это ожидаемое поведение), НО нет обработки ситуации когда пользователь нажал "Отклонить" - аналитика всё равно работает

**Ожидаемый результат:**
Если пользователь отклонил cookie:
1. Yandex Metrika не должна загружаться
2. ИЛИ должна работать в режиме без сбора личных данных

**Фактический результат:**
Metrika работает независимо от выбора пользователя

**Рекомендация:**
Проверять значение `localStorage.getItem('cookieConsent')` перед инициализацией Metrika

**Статус:** 🟡 Open (GDPR compliance)
